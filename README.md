# Rethinking Misinformation Metrics: 
**Including Polarisation and Political Unrest for Country-Level Comparison**

This repository contains the code, data processing scripts, and analysis notebooks developed for my Master’s thesis.

In an age where misinformation spreads rapidly through algorithmic systems and polarized media and social environments, this project reconsiders how we measure societal vulnerability to false or misleading information. It introduces a new country-level index that expands beyond traditional literacy-based approaches (e.g., the Media Literacy Index), by incorporating two often-overlooked dimensions:

- **Political Polarization**, derived from World Values Survey (WVS) individual-level data using LDA topic modeling.

- **Political Unrest**, using conflict incidence data from ACLED.

These indicators are combined with other established metrics (media freedom, education, civic participation) and synthesized via Principal Component Analysis (PCA) to generate a multidimensional vulnerability index.

🎯 Research Question

*RQ1: How does the current misinformation risk ranking from the Media Literacy Index (MLI) differ from a ranking that includes polarization and political unrest as indicators for misinformation vulnerability?*
